# Sticker Layout & Cutline Studio

เว็บแอปจัดวางสติกเกอร์สำหรับงาน Print & Cut ทำงานในเบราว์เซอร์ทั้งหมด ไฟล์ไม่ถูกส่งออกจากเครื่อง

**สถานะ: M4 Marks & Export ตาม SRS v1.1 (ส่งตรวจ)** จัดวาง สร้างเส้นตัด จัดเรียงหลายหน้า ใส่ Registration Marks และส่งออกไฟล์พิมพ์กับไฟล์ตัดได้
ดู [รายงานสถานะ](docs/STATUS.md), [Architecture](docs/ARCHITECTURE.md) และ [Traceability](docs/TRACEABILITY.md)

## วิธีรัน

ต้องมี Node.js 20 ขึ้นไป ไม่ต้อง `npm install`

```bash
npm start
```

แล้วเปิด http://localhost:8080

บน Windows ถ้า PowerShell ไม่ยอมรัน `npm` ให้ใช้ `npm.cmd start`
ถ้าไม่มี Node ใช้ `python3 -m http.server 8080` ในโฟลเดอร์นี้แทนได้
ต้องเปิดผ่าน Web Server เพราะเบราว์เซอร์ไม่โหลด ES Modules จาก `file://`

## วิธีใช้

1. ตั้งขนาดกระดาษและ Margin ที่แผงขวา
2. ลากไฟล์ PNG หรือ JPG มาวาง หรือกด "เพิ่มภาพ"
3. ปรับจำนวนที่แผงซ้าย
4. คลิกชิ้นงานแล้วลากย้าย ลากมุมเพื่อย่อขยาย หรือกรอกค่าเป็น มม.
5. กด Shift ค้างแล้วคลิก หรือลากคลุมพื้นที่ว่าง เพื่อเลือกหลายชิ้น แล้วจัดแนวหรือจัดลำดับชั้นที่แผงขวา
6. กด "เส้นตัด" ที่แบบนั้นเพื่อปรับและดูตัวอย่าง หรือกด "สร้างเส้นตัดทุกแบบ" แล้วตรวจผลก่อนใช้งานจริง
7. ถ้าใช้ Print & Cut เปิด "Registration Marks" ที่แผงขวา เลือกชุดมาร์ค ปรับค่า แล้วกด "ใช้ชุดมาร์คนี้" ทำก่อนจัดเรียง เพราะชิ้นงานต้องหลบพื้นที่รอบมาร์ค
8. ตั้งระยะห่างแล้วกด "เรียงตามแถว" หรือ "จัดให้ประหยัด" ที่แผงขวา ถ้าใช้หลายแบบหรือหลายมุมหมุนอาจใช้เวลาเป็นนาที กดยกเลิกได้
9. ใช้เมนู "มุมมอง" ดูเฉพาะภาพหรือเฉพาะเส้นตัด แล้วกด "ส่งออก" เลือกไฟล์ ตรวจ Preflight แล้วกดส่งออก

**มาร์ค MicroCut 30Q ยังไม่ได้ยืนยันกับคู่มือหรือเครื่องจริง** ต้องแก้ขนาดและตำแหน่งให้ตรงกับเครื่อง แล้วทดลองตัดก่อนใช้งานจริง

| ปุ่ม | การทำงาน |
|---|---|
| Ctrl+Z, Ctrl+Y | ย้อนกลับ, ทำซ้ำ |
| ลูกศร | เลื่อน 1 มม. (Shift 10 มม., Alt 0.1 มม.) |
| ▲▼ หรือลูกศรขึ้น/ลงในช่องตัวเลข | เพิ่ม/ลดค่า (Shift ×10, Alt ×0.1) |
| Delete | ลบชิ้นหรือมาร์คที่เลือก |
| Ctrl+A, Ctrl+D | เลือกทั้งหมด, ทำซ้ำ |
| ล้อเมาส์ | ซูมที่ตำแหน่งเคอร์เซอร์ |
| Space + ลาก หรือปุ่มกลางเมาส์ | เลื่อนมุมมอง |

งานบันทึกอัตโนมัติในเบราว์เซอร์นั้น เปิดใหม่แล้วกลับมาที่เดิม

## ทดสอบ

```bash
npm test            # Unit Tests ไม่ต้องติดตั้งอะไรเพิ่ม
npm run test:e2e    # ต้องมี Playwright และ Chromium
npm run testdata    # สร้างชุดทดสอบใหม่ ต้องมี Python และ Pillow
```

ถ้า Playwright ไม่ได้อยู่ที่ `/opt/npm-tools` ให้ตั้ง `PLAYWRIGHT_FROM=/path/to/project/`
ใช้ Chrome หรือ Edge ที่ติดตั้งในเครื่องแทน Chromium ของ Playwright ได้ด้วย `PLAYWRIGHT_CHANNEL=chrome` หรือ `msedge`
